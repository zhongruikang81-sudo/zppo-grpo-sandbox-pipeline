# ZPPO 强化对齐与大模型工具交互：SFT vs GRPO vs ZPPO 全维度终极研究报告

> **项目名称**：基于 ZPPO (Zero-shot Preference Policy Optimization) 框架的大模型数学沙箱自愈与对齐优化  
> **评测基座**：Gemma-2-2B-SFT  
> **评测环境**：本地物理沙箱（支持多轮 Python 代码执行、Traceback 反馈捕获及 大模型辅助过程评分与步骤奖励挽救）  

---

## 摘要 (Executive Summary)

本研究旨在评估并探索基于教师-学生偏好课程学习的 **ZPPO 强化对齐算法** 在提升大语言模型（LLM）工具调用与逻辑推理能力上的作用。通过对比 **SFT Baseline**、**GRPO-1800**、**ZPPO-600 (中期)** 与 **ZPPO-960 (后期)** 在两个不同难度数据集上的全量跑分，本报告得出两个核心学术结论：
1. **早停甜点（Sweet Spot）定理**：在两个测试集上，**ZPPO-600（中期）均代表了模型的最佳综合表现**。到了 ZPPO-960（后期），模型出现了明显的过拟合、风格偏移（Style-Drift）与多轮 Debug 纠错自愈能力的大倒退。
2. **工具调用信念强推效应（Tool-Use Policy Enforcement）**：在普通混合集（NuminaMath）上，ZPPO 将模型的写码频次从 28% 强推至 70%+。而在硬核难题集（MATH Level 3 & 4）上，当 SFT 和 GRPO 面临抽象公式产生避难情绪、写码率崩溃缩水至 10%-14% 时，**ZPPO 依然成功将写码率锚定在 50% 左右**，以 17.29% 的准确率实现了对 SFT（13.08%）和 GRPO（12.15%）的两位数百分比相对超越。

## 一、 方法学与 ZPPO 实现架构

### 1.1 动态课程重放缓冲区 (PRB)
为了解决在线强化探索时正向反馈极度稀疏的问题，ZPPO 引入了 **Prompt Replay Buffer (PRB)**。
* 当装载新问题时，首先由当前学生模型（Student）进行预考。若首枪直接正确，则**过滤跳过**以节省算力。
* 若做错，则将该题放入缓冲区，用确定性教师模型生成正确轨迹，同时将学生自己的错误轨迹记入“错题集种子”。
* 问题在 Buffer 中满足 $N=2$ 次连续做对即**毕业（Graduate）**，若停留 $M=5$ 个 Step 仍未做对则**退休（Retire）**。

### 1.2 双候选对比反思 (BCQ) 与 LoRA 分布对齐
在每个训练 Step 中，PRB 动态提取学生最近的错题轨迹与教师的对题轨迹，随机打乱构成 **Bi-candidate Comparison Query (BCQ)**，强迫学生模型指出 Candidate A 与 B 中的错误并说明原理，再写码求解。
* **无 Critic 魔改 (GRPO Baseline)**：对于同一个 BCQ 提示词，策略网络同时采样 $G=2$ 个 Rollout 轨迹，以其均值作为 Baseline 计算相对优势 $Advantage_i = Reward_i - \overline{Reward}$。若组内得分相同则触发 **Zero-Advantage Skip**，跳过梯度更新。
* **PPO Token-level 剪切与 KL 约束**：基于 Response 掩码计算 Token 级别的策略剪切损失（$\epsilon = 0.2$），并以 LoRA 适配器失效状态作为参考模型预测，引入 KL 惩罚（$\beta = 0.01$），保证策略更新的平稳性。

## 二、 实验一：NuminaMath 混合测试集 (500题全量评测)

500题测试集用于评估模型在基础代数、应用题上的**对齐习惯**与**防过拟合鲁棒性**。

### 2.2 核心挖掘结论
1. **写码与得分习惯绑定**：SFT 答对题目中仅有 36.73% 依赖代码，到了 ZPPO-960，**答对题目的写码率飙升至 79.75%**。写码成为了 ZPPO 绝对的核心得分支柱。
2. **写码题目的胜率红利**：无论哪个模型，**写码题的正确率（34%-38%）均显著高过不写码题的正确率（23%-27%）**，沙箱交互在复杂推理中起到了物理防错作用。
3. **960步的纠错自愈退化**：虽然 ZPPO-960 的首轮一枪直达率最高（23.80%），但其**二轮修改成功率（47.57%）和执行成功率（60.94%）均低于中期的 ZPPO-600**。模型后期开始出现过度写码、车轱辘话 Debug 和伪报错诊断，表明 600 步为更优的早停检查点。

### 3.3 核心挖掘结论
1. **难题下的“工具避难本能”**：
   在 Level 3 & 4 极难题目面前，SFT（14.02%）和 GRPO（10.28%）由于缺乏强力的偏好约束，出现了极其严重的写码率收缩，绝大多数题目选择退回纯文本口算，导致整体得分锁死在 12%-13%。而 **ZPPO 策略模型成功突破了避难本能，将写码率强行稳定在 50% 左右**。
2. **ZPPO-600 的统治级领先 (+5.14% / +4.21%)**：
   在过滤掉几何噪音后，**ZPPO-600 取得了 17.29% 的最高准确率**。这证明了强制工具调用加反思课程能够在难题区建立起真正的逻辑代差。
3. **ZPPO-960 的纠错逆袭系统性崩溃 (15.2% -> 4.3%)**：
   * 在第一轮代码报错后，**ZPPO-600 最终有 15.22% 的题目能够通过多轮 Debug 调试拯救成功并做对**。
   * 而到了 **ZPPO-960，这一救回率遭遇断崖式下跌，仅剩 4.35% (46次报错仅救回2次)**。
   * 这强力证明了：后期强化（960步）对策略模型造成了显著的对齐偏置伤害，导致其 Debug 逻辑变得刻板、陷入话术循环或出现环境变量幻觉，使其在逆境下的自愈能力彻底丧失。
4. **反思能力的文字推理外溢**：
   ZPPO-600 的**不写码题准确率（17.43%）显著高于 SFT（13.04%）与 GRPO（11.46%）**。这说明 BCQ 反思比对训练不仅优化了写码，还净化了模型底层的逻辑 Prior，使得模型即使不写码，脑算直觉也更加严密。

## 四、 核心学术结论与未来改进建议

1. **早停检查点（Sweet Spot）的普适性**：
   无论是混合集还是硬核难题集，2B 小模型在 RL 强化学习训练到 **600 步左右**时即达到了推理能力与泛化鲁棒性的黄金结合点。继续推进训练（960步）虽然能略微拔高第一枪的直觉命中率（23.8% vs 23.0% / 5.61% vs 5.14%），但会造成纠错模块（调试成功率与自愈挽救率）的灾难性退化。
2.  **视觉图表题对纯文本沙箱的噪音污染**：
    实证显示，含有 `[asy]` 的几何题在没有多模态输入的情况下，对写码策略模型是极大的惩罚（强行写码坐标建系极易失之毫厘谬以千里），这也警示我们在构建物理沙箱评测集时，必须严格做好“多模态”与“纯逻辑计算”的解耦。
3. **下一步改进建议**：
   * **动态 KL 惩罚控制**：在训练后期自适应调大 $\beta$ 惩罚项，以限制语言风格偏移，防止多轮纠错自愈能力崩溃。
   * **强化多轮 Debug 专用奖励**：在 GRPO/PPO 奖励设计中，不仅对最终结果给分，应对“从首轮报错到二轮调试运行成功”这一**自愈行为**给予小额的正向塑形奖励（Shaping Reward）。
